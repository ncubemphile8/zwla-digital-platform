# ZWLA Digital Platform — VanillaWebz concept

A cinematic, mobile-first concept for the Zimbabwe Women Lawyers Association (ZWLA): public-facing storytelling, access-to-justice intake, and an internal operations dashboard prototype.

## Stack
- Next.js App Router + React + TypeScript
- GSAP for cinematic transitions and scroll choreography
- Framer Motion for component and layout motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Important demo boundaries
- This is a **demonstration prototype**, not a production legal case-management system.
- All dashboard cases and metrics are fictional sample data.
- Public copy is a design concept and must be verified with ZWLA before publication. Do not imply the site is an official ZWLA service until authorised.
- Never enter real survivor, client, or confidential case information in this demo.
- Before production: confirm brand and media permissions; verify every office/contact/programme; conduct safeguarding, privacy, security and accessibility reviews; implement secure backend, authentication, role-based access, audit logging, retention rules, encryption and tested backups.

## Motion principles
Signature gavel intro, cinematic green transition curtain for page changes, scroll-revealed editorial sections, staggered media cards, and a shorter path to “Get Legal Help”. Respects reduced-motion preferences and keeps navigation usable without animation.
